ML Phase Summary — Three Models, 70/15/15 Split

Three classifiers (Logistic Regression, Random Forest, LightGBM) were trained on 8 engineered features including source OHE, source_tier, owner/company frequency encoding, notes sentiment, and word count. All three achieve ROC-AUC ≈ 0.50–0.52 — marginally above random chance. Best model: Logistic Regression (Val AUC = 0.5113). This near-random performance is the analytically correct result given the narrow 1.4 pp win-rate spread across sources.

All Metrics — Test Set

Accuracy, Precision, Recall, F1 Score, ROC-AUC, PR-AUC — actual results from ml_phase5_metrics.json

Why ROC-AUC ≈ 0.50–0.52? Source win rates span only 1.41 pp (9.28%–10.69%). Notes sentiment difference Won vs Lost is 0.0071. No temporal, financial, or behavioral features are available. High train AUC for RF/LGBM (0.65/0.69) vs near-random val/test AUC confirms overfitting with no generalizable signal. A useful predictive model would require: deal value, industry, response time, engagement events, and follow-up counts.

Causation disclaimer: All importances and coefficients describe learned statistical associations — not causal effects. Higher values for Podcast/Referral/Partner channels reflect observed win-rate differences in the data. Switching channels based on these findings requires validation via controlled experiments. Permutation importance confirms no feature provides genuine predictive lift beyond noise.
